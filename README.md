# Cadernos Prontos

Repositório para os cadernos acadêmicos digitais.

## Caderno do Estudante de Gastronomia

Pasta: `/gastronomia`

A primeira etapa do projeto é a biblioteca de **Resumos Prontos**, com visual em galeria inspirado em ferramentas de organização de conhecimento.

### Estrutura desta versão

- 6 módulos principais
- 36 disciplinas
- 108 resumos completos
- galeria de módulos
- galeria de disciplinas
- páginas individuais por assunto
- resumo, pontos-chave, foco para prova/concurso e aplicação prática
- busca global
- favoritos
- histórico de conteúdos recentes
- progresso de leitura salvo no navegador
- interface responsiva

### 6 módulos

1. Fundamentos da Gastronomia
2. Técnicas de Cozinha
3. Panificação, Confeitaria e Bebidas
4. Cozinhas do Brasil e do Mundo
5. Segurança, Qualidade e Sustentabilidade
6. Gestão, Eventos e Formação Acadêmica

### Próximas etapas planejadas

A estrutura lateral já reserva espaço para os próximos módulos do caderno:
- Flashcards
- Mapas mentais

Eles podem ser adicionados depois sem alterar a organização dos resumos.

### Arquivos

- `gastronomia/index.html` — estrutura da aplicação
- `gastronomia/styles.css` — interface em galeria
- `gastronomia/data.js` — biblioteca acadêmica preenchida
- `gastronomia/app.js` — navegação, pesquisa, favoritos e progresso
